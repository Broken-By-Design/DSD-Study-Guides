Pandas: Core DataFrames

PANDAS
Context: In Task 4a, you will often need to read and process structured data. Pandas stores this data in a DataFrame—think of it as a programmatic spreadsheet. Rows represent observations (e.g., individual orders), and columns represent variables (e.g., Order ID, Price).

Series vs. DataFrames

Pandas Series

A single column of data. It is a 1-dimensional array with axis labels (an index).

ages = pd.Series([22, 35, 58])

Pandas DataFrame

A 2-dimensional table made of multiple Series objects sharing the same index.

Creating DataFrames Manually

From a Dictionary

Keys become column names, lists become the rows.

df = pd.DataFrame({
  "id": [1, 2, 3],
  "score": [70, 85, 92]
})

From a List of Lists

Specify the column names explicitly.

df = pd.DataFrame(
  [[1, 70], [2, 85], [3, 92]],
  columns=['id', 'score']
)

Importing & Exporting Data

PANDAS
ESP Briefing: The client will typically provide raw data as a CSV file, JSON file, or SQLite database. You must ingest this correctly to begin the task.

Input (Reading Data)

CommandWhen to use in the exam
pd.read_csv('data.csv')Most common. Reads a standard comma-separated file.
pd.read_excel('data.xlsx')If the data is provided in a native Excel format (requires openpyxl).
pd.read_json('data.json')If the brief provides a JSON API response or file.
pd.read_sql(query, conn)If querying an SQLite database. Requires sqlite3.connect().

Handling CSV Quirks

Sometimes the provided file has no headers, or uses different separators.

  • No Headers: pd.read_csv('file.csv', header=None, names=['ID', 'Name'])
  • Semicolon Separator: pd.read_csv('file.csv', sep=';')

Output (Saving Files)

Writing to CSV

Required to output a "processed report".

df.to_csv('report.csv', index=False)

* Always use index=False unless row numbers carry meaning, otherwise you'll generate a junk extra column!

Writing to SQL

To update the main application database.

df.to_sql('table', conn, if_exists='replace')

Filtering & Searching

PANDAS
The Task requirement: "The dashboard must only show sales data for customers aged 18-25 located in London." Filtering allows you to isolate exact rows.

1. Boolean Masking

Pass a True/False logical condition inside the brackets to extract matching rows.

df[df['Age'] > 18]

Multiple conditions: Use & (AND) or | (OR). Parentheses are mandatory!

df[(df['Age'] >= 18) & (df['City'] == 'London')]

2. The `query()` Method

Allows cleaner syntax as a string. Highly recommended for readability.

df.query("Age >= 18 and City == 'London'")

3. Advanced String & List Filtering

CommandPurpose
df[df['Status'].isin(['Active', 'Pending'])]Check if the cell value exists within a specific list.
df[df['Name'].str.contains('John')]Regex/String search. Finds rows where "John" is part of the name.
df[df['Age'].between(18, 25)]Grabs rows where Age is inclusively between 18 and 25.

loc vs. iloc

loc: Label-based. Selects by the names of the columns/indexes. df.loc[0:5, 'Name':'Age']
iloc: Integer-based. Selects by the numeric position (0-indexed). df.iloc[0:5, 0:2]

Cleaning & Formatting

PANDAS
Crucial Exam Trap: Often, the data provided in Task 4a is "dirty". Dates might be stored as text, prices might have "£" symbols, and fields might be empty. You must clean the data before plotting it!

Handling Missing Data (Nulls / NaNs)

Drop Empty Rows

df.dropna(subset=['Email'])

Removes any row where the Email column is blank.

Fill Empty Values

df['Score'].fillna(value=0, inplace=True)

Replaces blanks with a default value (e.g. 0).

Fixing Data Types

Converting Strings to Datetimes

Essential if you need to group data by Month or Year.

df['Order_Date'] = pd.to_datetime(df['Order_Date'])
# Now you can extract parts of the date easily:
df['Year'] = df['Order_Date'].dt.year

Cleaning Text to Numbers

If a price is imported as "£45.00" (String), Matplotlib cannot do maths on it!

# 1. Replace the pound sign with nothing
df['Price'] = df['Price'].str.replace('£', '')
# 2. Convert the column to float (decimal)
df['Price'] = df['Price'].astype(float)

Grouping & Summarising

PANDAS
Task Requirement: "Generate a report showing the total revenue per department." Grouping squashes many rows down into summary metrics.

Basic Summaries

Descriptive Stats

df.describe()

Prints mean, min, max, std dev for all numeric columns.

Frequency Counts

df['Dept'].value_counts()

Counts how many times each Dept appears.

Single Aggregation

df['Price'].sum()
mean(), min(), max()

Grouping Data (`groupby`)

Step 1: Pick the column to group by. Step 2: Pick the column to calculate. Step 3: Apply the math function.

revenue_by_dept = df.groupby('Department')['Revenue'].sum()

This outputs a Pandas Series where the Index is the Department names, and the values are the summed revenues.

Advanced: Multiple Aggregations

If you need the average order value AND the total number of orders in one go:

summary = df.groupby('Region').agg({
    'Revenue': 'mean',    # Average revenue
    'OrderID': 'count'    # Number of orders
})

Combining Data Sets

PANDAS
Exam Scenario: You are provided a `users.csv` and an `orders.csv`. You must join them on `user_id` to map a user's name to their purchase history.

Relational Joins (`pd.merge`)

Similar to SQL JOIN statements. It maps rows from two DataFrames based on a shared column.

Join TypeCommandResulting Data
Inner Joinpd.merge(df1, df2, how='inner', on='ID')Default. Retain ONLY rows that exist in both sets.
Left Joinpd.merge(df1, df2, how='left', on='ID')Keep all rows from left df (df1). Fill missing right data with NaNs.
Outer Joinpd.merge(df1, df2, how='outer', on='ID')Retain ALL values, all rows from both sets.

Stacking Data (`pd.concat`)

Appending Rows

Stacking `jan_data.csv` on top of `feb_data.csv`.

pd.concat([jan, feb])

If the original indexes overlap (e.g. both start at 0), add ignore_index=True to generate a fresh, continuous numbering system.

Appending Columns

Placing two datasets side-by-side.

pd.concat([df1, df2], axis=1)

Matplotlib: Basic Plots

MATPLOTLIB
Context: Visualising data is a required competency. Matplotlib perfectly handles 2D plots. Always start your file with: import matplotlib.pyplot as plt

The Core Plot Types

Line Plot

Shows trends over a continuous variable (like time). Best for "Revenue over 12 months".

plt.plot(x, y)

Bar Plot

Shows distribution across categories. Best for "Sales per region".

plt.bar(categories, heights)

Scatter Plot

Shows individual data points, useful for finding correlation (e.g. Age vs Salary).

plt.scatter(x, y)

Histogram

Shows frequency distribution of numerical data (e.g. grouping ages into brackets).

plt.hist(data, bins=10)

Displaying the Result

In standard Python environments, Matplotlib draws graphs in memory. Nothing appears on the screen until you call the show function!

plt.show()

Customising Plots

MATPLOTLIB
Exam Tip: An unlabelled graph loses marks heavily. Always include a title, label your X and Y axes, and add a legend if plotting multiple lines.

Essential Labelling

CommandWhat it does
plt.title("Sales 2026")Adds a main title to the top of the plot.
plt.xlabel("Months")Labels the X-axis.
plt.ylabel("Revenue (£)")Labels the Y-axis. Include units if applicable!
plt.legend(["A", "B"])Adds a legend box to explain colors/lines.
plt.grid(True)Adds background gridlines for readability.

Aesthetic Tweaks

Line Customisation

You can change colors (c), line styles (ls), and markers.

plt.plot(x, y, color='red', linestyle='--', marker='o')

Rotating X-Axis Labels

If category names overlap (like long dates), rotate them!

plt.xticks(rotation=45)

Saving the Output to File

In the ESP, you are frequently asked to save the generated graph to a `.png` file.

plt.savefig('output_chart.png', dpi=300, bbox_inches='tight')

Note: Always call savefig() before plt.show()! If you call show() first, Matplotlib clears the active canvas, and your saved image will be a blank white square.

Subplots & Layouts

MATPLOTLIB
T Level Scenario: The client asks for a "dashboard image" containing a Bar Chart of regions AND a Line Chart of time trends displayed side-by-side.

The Object-Oriented Approach

Rather than using plt.* which affects the whole screen, we create a Figure (the window) containing multiple Axes (the individual plots).

fig, axs = plt.subplots(nrows=1, ncols=2, figsize=(10, 5))
  • fig: The entire window/page.
  • axs: An array containing the individual plot areas (axs[0] and axs[1]).

Plotting on Subplots

fig, axs = plt.subplots(1, 2)

# Plot on the first subplot (left)
axs[0].bar(regions, sales, color='blue')
axs[0].set_title("Sales by Region")
axs[0].set_ylabel("Revenue (£)")

# Plot on the second subplot (right)
axs[1].plot(months, trends, color='red')
axs[1].set_title("Revenue over Time")

plt.tight_layout() # Prevents labels from overlapping
plt.show()

Notice that plt.title() becomes axs[0].set_title() when using subplots!

Pandas Native Plotting

MATPLOTLIB
Shortcut Alert: Because Matplotlib and Pandas work so closely together, Pandas actually has Matplotlib built directly into it! This is often the fastest way to plot data in an exam.

The `df.plot()` Method

If your data is already grouped cleanly, you can plot it immediately without explicitly extracting X and Y variables.

# 1. Group the data
dept_revenue = df.groupby('Department')['Revenue'].sum()

# 2. Plot directly from the Pandas Series
dept_revenue.plot(kind='bar', color='purple', title='Revenue by Dept')

# 3. Use plt to show/save
plt.ylabel('Total Revenue (£)')
plt.tight_layout()
plt.show()

kind='barh'Horizontal bar chart (great for long category names).
kind='pie'Pie chart (automatically uses values for slices).

Exam Strategy: Task 4a

TASK 4A
Combining Pandas and Matplotlib: In the ESP, you will never use these libraries in isolation. You will use Pandas to process raw data, and Matplotlib to visualize the processed result.

The Standard 4-Step Workflow

1. Load

Read the provided CSV/JSON into a DataFrame.

2. Clean

Drop missing values, convert data types, and filter rows.

3. Aggregate

Group the data using `groupby()` to get summary metrics.

4. Plot

Create a chart. Add titles, labels, and save to a `.png` file.

A Perfect Full-Mark Example Snippet

import pandas as pd
import matplotlib.pyplot as plt

# 1. LOAD
df = pd.read_csv('raw_sales.csv')

# 2. CLEAN & FILTER
df.dropna(inplace=True)
df = df.query("Status == 'Completed'")

# 3. AGGREGATE
monthly_sales = df.groupby('Month')['Revenue'].sum()

# 4. PLOT & SAVE
monthly_sales.plot(kind='bar', color='#a855f7')
plt.title('Total Completed Sales by Month')
plt.xlabel('Month')
plt.ylabel('Revenue (£)')
plt.tight_layout()

plt.savefig('sales_report.png')
plt.show()
